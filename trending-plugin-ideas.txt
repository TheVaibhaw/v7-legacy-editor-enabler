1. AI AUTO IMAGE ALT-TEXT & SEO GENERATOR (GEMINI & OPENAI)
--------------------------------------------------------------------------------
[OVERVIEW]
A lightweight, zero-bloat plugin that automatically analyzes uploaded images in the
WordPress Media Library and generates accurate, SEO-optimized Alt-Text, Titles,
and Captions using vision AI APIs (Google Gemini Vision / OpenAI Vision).

[WHY IT IS TRENDING & HIGH DEMAND]
Every blogger, agency, and WooCommerce store owner faces the tedious task of manually
adding Alt-Text to thousands of product and blog images. Alt-Text is critical for
accessibility (ADA compliance) and Google Image Search ranking. Current solutions are
either expensive SaaS products or slow. An easy API key plugin will explode in downloads.

[HOW IT WORKS (TECHNICAL EXECUTION)]
1. Hook into `add_attachment` or `wp_generate_attachment_metadata` when an image is uploaded.
2. Send the image URL / base64 image data to Google Gemini Vision or OpenAI API.
3. Prompt AI: "Describe this image in one concise, SEO-friendly alt-text sentence under 125 characters."
4. Automatically update `_wp_attachment_image_alt` post meta and attachment `post_title`/`post_excerpt`.
5. Provide a Bulk Action button in `Media > Library` to process existing images in batches of 10/20 via AJAX.

[KEY FEATURES]
- Automatic Alt-Text generation on upload.
- One-click Bulk Alt-Text Generator for existing media library images.
- Choice of AI Providers: Google Gemini (Free tier API) or OpenAI.
- Customizable Prompt Settings (e.g., include target keywords, tone, language).
- Multi-language support (Generates Alt-Text in Hindi, Spanish, French, German, etc.).

[MONETIZATION / PRO ROADMAP]
- Free: 50 free AI credits / use own Gemini API key.
- Pro: Unlimited Bulk Processing, WooCommerce Product Image Auto-Naming, Image Compression.

2. NEXT.JS & VERCEL INSTANT REVALIDATION HELPER FOR HEADLESS WORDPRESS
--------------------------------------------------------------------------------
[OVERVIEW]
A developer-first plugin that integrates Headless WordPress with Next.js (App Router / Pages Router)
to trigger instant On-Demand Incremental Static Regeneration (ISR) on Vercel or custom Node servers
whenever posts, pages, or custom post types are published or updated.

[WHY IT IS TRENDING & HIGH DEMAND]
Modern web developers are rapidly switching to Headless WordPress with Next.js / Astro.
However, keeping the frontend static site updated when an editor publishes a post in WordPress
currently requires custom code. A plug-and-play webhook plugin solves this pain point instantly.

[HOW IT WORKS (TECHNICAL EXECUTION)]
1. Admin enters Next.js Secret Token and Revalidation Endpoint URL in Settings page.
2. Plugin listens to action hooks: `save_post`, `deleted_post`, `wp_trash_post`, `edited_terms`.
3. Constructs a payload containing `slug`, `post_type`, `action`, and signature hash (HMAC SHA-256).
4. Sends a non-blocking background HTTP POST request via `wp_remote_post()` to the Next.js API route `/api/revalidate`.
5. Shows a real-time status indicator in the WP Admin Top Bar (e.g., "Frontend Synced ✓").

[KEY FEATURES]
- One-click connection with Vercel, Netlify, and custom Next.js servers.
- Post-Type & Category specific webhook routing.
- On-demand Revalidate button directly in post edit screen metabox.
- Audit Log table showing recent revalidation requests and HTTP response codes.

[MONETIZATION / PRO ROADMAP]
- Free: Full single-site Next.js revalidation.
- Pro: Multi-frontend support, GraphQL cache clearing, Slack/Discord notification webhooks.

3. WOOCOMMERCE WHATSAPP DIRECT ORDER & QUICK BUY STICKY BAR
--------------------------------------------------------------------------------
[OVERVIEW]
A high-converting sales booster for WooCommerce that adds a customizable "Order on WhatsApp"
and "Quick Buy" button on product pages, allowing customers to send pre-filled order details
directly to the store owner's WhatsApp number.

[WHY IT IS TRENDING & HIGH DEMAND]
In India, South-East Asia, Middle East, and LATAM, over 60% of online shoppers prefer ordering
or inquiring via WhatsApp instead of going through complex cart checkout forms. Store owners
see instant 30%+ increase in conversions.

[HOW IT WORKS (TECHNICAL EXECUTION)]
1. Store owner sets WhatsApp Phone Number and custom pre-filled message template in admin settings.
2. Plugin hooks into `woocommerce_after_add_to_cart_button` and `wp_footer`.
3. Dynamically pulls product title, price, selected variations (color/size), and current URL.
4. Generates a deep link: `https://wa.me/{number}?text={encoded_message}`.
5. Renders a mobile-optimized floating sticky bar on product pages with single-click redirect.

[KEY FEATURES]
- One-click Order via WhatsApp on Single Product and Cart pages.
- Dynamic placeholders: `{product_name}`, `{product_price}`, `{product_url}`, `{sku}`.
- Mobile-only or Desktop-and-Mobile display toggles.
- Google Analytics / Facebook Pixel event tracking on WhatsApp button clicks.

[MONETIZATION / PRO ROADMAP]
- Free: Unlimited WhatsApp direct links & customizable button styles.
- Pro: Multi-agent routing (rotate between 3 phone numbers), automated WhatsApp Business API templates.

4. ELEMENTOR FORM TO GOOGLE SHEETS & WEBHOOK CONNECTOR
--------------------------------------------------------------------------------
[OVERVIEW]
A seamless addon for Elementor Pro Form widget that automatically appends form submissions
to a specified Google Sheet spreadsheet in real time without needing Zapier or Make.com.

[WHY IT IS TRENDING & HIGH DEMAND]
Elementor is used by 15M+ websites. Small businesses and agencies want form submissions saved
directly in Google Sheets for sales teams. Paid automation platforms (Zapier) get expensive quickly,
making a free native WP plugin extremely attractive.

[HOW IT WORKS (TECHNICAL EXECUTION)]
1. Registers a custom Form Action in Elementor Pro: `elementor_pro/forms/actions/register`.
2. Adds Google Sheets credentials and Sheet ID setting to the Elementor Form panel.
3. Upon form submission (`elementor_pro/forms/new_record`), extracts field IDs and values.
4. Uses Google Sheets API v4 (or Google Apps Script Webhook) to append a new row to the sheet.
5. Logs submission status in local WP database for fail-safe backup.

[KEY FEATURES]
- Direct Elementor Form integration without external paid subscriptions.
- Automatic column mapping (Name -> Col A, Email -> Col B, Phone -> Col C, Timestamp -> Col D).
- Support for multiple forms mapping to different Google Sheets.
- Local submission fallback log if Google Sheets API is temporarily unreachable.

[MONETIZATION / PRO ROADMAP]
- Free: Single Google Sheet mapping per site.
- Pro: Unlimited Google Sheets, Mailchimp/Hubspot integration, conditional mapping logic.

5. V7 CONTENT EDITOR POWERPACK (SUPERCHARGED CLASSIC EDITOR TOOLKIT)
--------------------------------------------------------------------------------
[OVERVIEW]
An all-in-one content editing manager that combines Classic Editor restoration, Classic
Widgets enabler, Block Directory disabler, and User Role based editor permissions.

[WHY IT IS TRENDING & HIGH DEMAND]
While Automattic's official Classic Editor only offers a basic global switch, thousands of
agencies need role-based control (e.g. Clients/Authors get Classic Editor, Developers get
Gutenberg). Upgrading your existing `v7-legacy-editor-enabler` plugin into this suite will
position it as the #1 alternative to Classic Editor.

[HOW IT WORKS (TECHNICAL EXECUTION)]
1. Filters `use_block_editor_for_post_type` and `use_block_editor_for_post` based on plugin settings.
2. Adds User Role condition check (`current_user_can()`) to determine active editor.
3. Filters `wp_is_application_passwords_available` and disables block directory via `remove_action('enqueue_block_editor_assets')`.
4. Restores classic TinyMCE button toolbar customizations (`mce_buttons` & `mce_external_plugins`).

[KEY FEATURES]
- Granular editor selection per Post Type AND per User Role (Admin, Editor, Author).
- Restore Classic Widgets alongside Classic Editor with 1-click.
- Disable Block Directory searching inside Gutenberg to prevent clients installing random block plugins.
- Hide Gutenberg notice banners and upgrade prompts for a clean admin environment.

[MONETIZATION / PRO ROADMAP]
- Free: Per-post-type and role-based editor switches.
- Pro: Custom TinyMCE font choices, custom admin CSS per post type, export/import settings.
